## Running Suite C

### Step 1: Regenerate fits (live R required)

```bash
# Requires R 4.4+ with compiled nlmixr2
python -m apmode.benchmarks.suite_c_phase1_runner
```

This step:
- Runs honest-mode estimation on each fixture (see "Metric definitions" below)
- Computes VPC, NPE, PIT calibration, and AUC/Cmax bioequivalence per fixture
- Writes results to `benchmarks/suite_c/phase1_npe_inputs.json`

### Step 2: Score the snapshot

```bash
python -m apmode.benchmarks.suite_c_phase1_cli \
  --inputs benchmarks/suite_c/phase1_npe_inputs.json \
  --out scorecard.json \
  --markdown-summary scorecard.md
```

### Step 3: Commit

```bash
git add benchmarks/suite_c/phase1_npe_inputs.json scorecard.json scorecard.md
git commit -m "score(suite-c): regenerate Phase-1 fixture scorecards post-[change]"
```

<Callout type="info">
**No scheduled CI job.** There is no cron-based regeneration of Suite C results. The committed `phase1_npe_inputs.json` is a generated snapshot, not continuously validated. Regenerate on-demand before citing Suite C results as evidence of methodology change.
</Callout>

## Metric Definitions

### NPE (Nonparametric Prediction Error)

**This is NOT classical NPDE.** APMODE's NPE is the **median absolute prediction error** from posterior-predictive simulations:

```
NPE = median(|observed_i - predicted_i|) / scale_i
```

where `scale_i` depends on the observation model:
- **Proportional**: divided by observed value
- **Additive**: raw residual
- **Combined**: divided by sqrt(observed² + 1²)

Reference: `apmode.benchmarks.scoring.compute_npe`. See [Design Decisions: Cross-Paradigm Circularity](/docs/reference/decisions/0004-cross-paradigm-circularity) for technical notes on why this metric is used and its limitations.

### PIT Calibration

**PIT** = Probability Integral Transform. For each observation, compute:
```
PIT_i = CDF(observed_i | simulated distribution)
```

A well-calibrated posterior should have PITs uniform on [0, 1]. Suite C reports the median PIT per fixture as a marginal calibration check (not a formal NPDE battery, but an observability metric).

### Honest-Mode Fit Contract

Suite C's "honest mode" ensures fairness:

1. **No literature seeding**: NCA estimators are never seeded with reference parameters
2. **Per-fixture k-fold CV**: Each fixture is fit on train folds with NPE computed on held-out test folds
3. **Fixed THETA**: Held-out NPE uses `fixed_parameter=True` (freeze THETA, fit ETAs only) so the cross-validation does not leak information between train and test

This contract is pinned by `tests/unit/test_suite_c_phase1_runner.py::test_run_fixture_apmode_side_never_seeded_from_literature_reference_params`.

## Fixture File Structure

Each fixture consists of three files:

### DSL Spec
**File**: `<dataset_id>.dsl.json`

```json
{
  "absorption": {...},
  "distribution": {...},
  "elimination": {...},
  "variability": {...},
  "observation": {...},
  "covariates": {...},
  "priors": {...}
}
```

Export via `DSLSpec(...).model_dump_json(indent=2)`.

### Literature Reference
**File**: `<dataset_id>.yaml`

```yaml
literature_reference:
  title: "Propofol Population Pharmacokinetics in Adults"
  authors: ["Eleveld DJ", "Colin P", ...]
  year: 2018
  doi: "10.1016/j.bja.2018.01.018"
  journal: "British Journal of Anaesthesia"
  volume: 120
  issue: 5
  pages: "942-959"

reference_params:
  CL:
    typical_value: 1.85
    unit: "L/h"
  V1:
    typical_value: 18.1
    unit: "L"

parameterization_mapping:
  TVCL: "CL"
  TVV1: "V1"
```

## Adding a New Fixture

1. **Decide on a stable `dataset_id`** (snake_case, lowercase)
2. **Create the DSL spec**:
   ```python
   spec = DSLSpec(...)
   with open(f"benchmarks/suite_c/{dataset_id}.dsl.json", "w") as f:
       f.write(spec.model_dump_json(indent=2))
   ```
3. **Create the literature fixture YAML** with `LiteratureReference`, `reference_params`, and `parameterization_mapping`
4. **Register in the loader**:
   ```python
   # src/apmode/benchmarks/literature_loader.py
   PHASE1_MLE_FIXTURE_IDS.append(f"{dataset_id}")
   ```
5. **Regenerate**:
   ```bash
   python -m apmode.benchmarks.suite_c_phase1_runner
   python -m apmode.benchmarks.suite_c_phase1_cli ...
   ```
