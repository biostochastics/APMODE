This page summarizes recent release highlights. The complete, authoritative changelog —

[`CHANGELOG.md`](https://github.com/biostochastics/APMODE/blob/main/CHANGELOG.md) at the

[semantic versioning](https://semver.org/).

<Callout type="info">
  APMODE tracks two version notions on purpose. The **declared** version is the milestone
  being built toward; the **runtime** version is the artifact identity of the installed
  bytes (written from VCS tags). `apmode --version` shows both when they differ.
</Callout>

## v0.6.1-rc2

- **HTTP API surface** — `apmode serve`, `POST /runs`, and the full cancellation
  lifecycle. Loopback by default; refuses non-loopback binds without `--allow-public` +
  `APMODE_API_KEY` + `--dataset-root`. See the [HTTP API reference](/docs/reference/http-api).
- **Suite C** — Phase-1 MLE + Bayesian fixtures with on-demand NPE scoring (no scheduled
  CI job). See [Suite C](/docs/reference/benchmarks/suite-c).
- **SOTA absorption preview forms** — `Erlang`, `ParallelFirstOrder`, and `SumIG`. See
  [ADR-0003](/docs/reference/decisions/0003-sota-absorption).
- **RO-Crate projector hardening** — sealed `_COMPLETE` SHA-256 sentinel; `apmode validate`
  refuses unsealed bundles.
- **Agentic-LLM QA** — a prompt-injection fix on covariate-name flow, an adversarial
  red-team test suite, and an advisory `trajectory_compliance.json` verdict flagging
  degenerate-optimization patterns across a run. Gate policy schema bumped `0.7.0 → 0.7.1`.
